# 🌦️ Power BI Weather & Daylight Dashboard

## 📌 Overview
This Power BI dashboard analyzes global weather data with a focus on:
- Sunrise, Sunset, Moonrise, Moonset
- Daylight hours by country
- Dynamic filtering using numeric and field parameters

## 🧠 Key Features
- Numeric parameter to filter countries by minimum daylight hours
- Field parameter to switch between sunrise, sunset, moonrise, and moonset
- DAX measures for daylight calculation
- Clean star-schema-ready data model
- Interactive slicers and visuals

## 🛠 Tools Used
- Power BI Desktop
- DAX
- GitHub
